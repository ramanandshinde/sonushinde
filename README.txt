SIXPLUS integrated demo storefront

Files:
- index.html: main storefront
- style.css: storefront styling
- script.js: product filtering, cart, localStorage and checkout navigation
- checkout.html: shipping form, payment options, order summary and SIX10 demo coupon

Run: keep all four files in the same folder and open index.html using VS Code Live Server.
The checkout and coupon are frontend demos only. No real order or online payment is processed.
